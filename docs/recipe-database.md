# 食谱数据库 (Refreshed A+B+C)

## 数据源与变更记录

- **食谱原件处理**：原来的 `犬用食谱.docx` / `犬用食谱Disable.docx` 为旧版非结构化二进制，已从 App 静态资源中移除；当前以 `docs/source/犬用鲜食配方_A+B+C_40种优化版_营养合规审查（0630）.xlsx` 和本文件结构化数据为准。
- **核心优化规则**：
  - **食材刷新**：完全剔除高风险豆类（如青豆等），新增优质单一蛋白及膳食纤维物料（如金枪鱼白肉、兔里脊、鸭小胸、全熟燕麦片、山药丁、冬瓜丁、西兰花等）。
  - **模块化配比 (A+B+C)**：
    - **A包**：鲜食基础包（40种优化配方），占比约 95% - 98%。
    - **B包**：全价营养包（必需，7类精准匹配生命阶段与功能）。
    - **C包**：功能支持包（可选，包含美毛、关节、肠胃、护肝等靶向增强）。

---

## 7类全价营养包 (B包) 定义
1. **幼犬成长营养包B** — 适用小型/中型幼犬成长发育。
2. **大型幼犬稳骨控钙营养包B** — 适用大型幼犬，钙磷精确控制，窄比例防骨关节疾病。
3. **成犬维护营养包B** — 适用常规成犬日常维护。
4. **成犬/美毛基础营养包B** — 强化 Omega-3 和微量皮脂元素。
5. **成犬/护肝基础营养包B** — 低矿物元素负担，养肝护肾。
6. **老年犬轻负担营养包B** — 低磷少钙，支持老年机能减负。
7. **低敏单一蛋白营养包B** — 纯游离态矿物质预混，无过敏载体。

---

## 7类功能支持包 (C包) 定义
1. **脑发育支持功能包C** — DHA藻油/胆碱/牛磺酸。
2. **美毛护肤支持功能包C** — 卵磷脂/生物素/有机锌/天然维生素E。
3. **护肝支持功能包C** — 水飞蓟素/胆碱/牛磺酸/姜黄素。
4. **肠胃健康支持功能包C** — 果寡糖益生元/酵母后生元。
5. **关节支持功能包C** — 葡萄糖胺/软骨素/MSM/透明质酸。
6. **心脏健康支持功能包C** — 辅酶Q10/L-肉碱/牛磺酸。
7. **抗炎免疫支持功能包C** — 酵母β-葡聚糖/蓝莓多酚/姜黄素。
