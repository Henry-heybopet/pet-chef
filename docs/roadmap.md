# 开发路线图

## 阶段 1：项目整理

- 建立 README 和 docs 文档入口。
- 明确产品定义目录、本地软件目录、GitHub 仓库之间的关系。
- 清理 Office/WPS 临时文件和系统文件进入 Git 的问题。

## 阶段 2：需求对齐

- 从产品定义资料中提炼正式 PRD。
- 将 UI 设计和提示词整理到 `docs/ui-notes.md`。
- 将设备控制和云平台相关内容整理到 `docs/device-integration.md`。

## 阶段 3：软件稳定化

- 梳理前端页面流程。
- 梳理后端/API 接口。
- 补充最小可用的运行说明和环境变量说明。
- 加入基础测试或手动验收清单。

## 阶段 4：产品闭环

- 完成犬只档案、AI 分析、食谱推荐、制作流程的完整体验。
- 对接真实设备或模拟设备状态。
- 准备演示版本和用户测试版本。

## 当前优先级

1. 把产品定义资料转成开发可执行的 Markdown。
2. 清理仓库当前未提交状态。
3. 补充环境变量说明，避免 `.env` 内容进入 Git。
