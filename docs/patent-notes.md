# 专利与技术壁垒

> 本文件是从现有产品定义、专利建议和技术创新分析中提炼出的研发摘要，不等同于正式专利法律意见。正式申请前应由专利代理人复核。

## 核心发明方向

建议围绕“基于微压蒸汽与力矩反馈控制的宠物鲜食烹饪设备”建立专利组合。

核心技术链条：

```text
上置驱动 + 无孔内胆
  -> 提升清洁和防漏
  -> 消除底部动密封摩擦干扰
  -> 提升电机负载信号纯度
  -> 支持力矩/电流/功率反馈判熟
```

```text
微压蒸汽低温烹饪
  -> 表面熟化锁水
  -> 双轴低速撕扯暴露内部
  -> 蒸汽继续作用于核心
  -> 兼顾肉丝口感和均匀熟化
```

## 主要创新点

### P1：上置驱动 + 无孔内胆

- 电机设置在上方。
- 搅拌轴自上向下延伸。
- 内胆底部无动力穿孔。
- 解决底部密封、漏水、清洁死角和信号干扰问题。

### P2：双轴低速撕扯

- 至少两个搅拌轴。
- 低速、高扭矩运行。
- 目标不是切碎，而是模拟手工撕肉。
- 区别于传统刀片高速剪切和普通搅拌。

### P3：力矩反馈判熟

- 采集电机负载参数，包括电流、功率或转矩。
- 根据肉类纤维从高抗力到低抗力的变化判断熟化状态。
- 关键在于识别固体肉类纤维的结构性解体，而不是传统料理机的流体黏度变化。

### P4：蒸汽 + 撕扯协同

- 先让食材表面熟化。
- 再通过双轴撕扯剥离已熟层，暴露未熟核心。
- 微压蒸汽继续作用于内部，提升热渗透效率。
- 解决大块肉类低温熟化慢、不均匀的问题。

### P5：称重 + 力矩闭环控制

- 称重模块获取初始食材重量。
- 根据重量设定初始加热时间和搅拌时机。
- 加热过程中根据电机负载反馈动态修正时间。
- 形成“称重 -> 初始模型 -> 加热 -> 力矩反馈 -> 动态修正 -> 停机”的闭环。

### P6：微压蒸汽水槽和隔离结构

- 内胆底部设置 30-50ml 下凹式水槽。
- 蒸架/隔离结构建议孔径 3-5mm。
- 目的：允许蒸汽上升和原汤回流，同时拦截碎肉掉入水槽，降低干烧糊底风险。

## 软件相关专利线索

软件和算法层可以配合硬件申请：

- 基于电机负载曲线的肉类熟化判定方法。
- 基于食材重量和负载反馈的自适应烹饪时间修正方法。
- 基于食材百分比、宠物档案和设备参数的鲜食制作控制系统。
- 云端食谱参数与设备控制参数同步的方法。

## 需要工程补证的数据

专利文件中多次提到需要工程数据支撑，建议研发阶段补齐：

- 机头底部密封剖面图。
- 双轴间距、夹角、转速范围和搅拌棒几何参数。
- 30-50ml 水槽的蒸汽效率测试。
- 3-5mm 孔径的回流、拦渣和糊底对比实验。
- 不同重量食材的电机电流/扭矩曲线。
- 生肉高阻平台、熟化阻力下降、曲线方差变化等特征点。
- 50g、200g、250g 等不同重量下的熟化一致性。
- 刀片切碎与双轴撕扯的肉丝完整度对比。
- 清洗耗时对比。

## 对研发的约束

为了保留专利壁垒，后续实现时应尽量保持这些概念的一致性：

- 不要把核心卖点退化为普通食谱 App。
- 不要只做固定时间和固定温度控制。
- 后端数据结构要能承载食材重量、设备参数、负载反馈和动态修正。
- UI 中的“一键烹饪”应展示设备参数和阶段，而不只是倒计时。
- 如果真实设备暂时没有力矩反馈，也应在架构上预留该字段和状态。
