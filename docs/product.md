# 产品定义

## 产品名称

宠物鲜食机 / Pet Chef

## 产品定位

面向宠物家庭的智能鲜食制作设备，通过犬只信息、营养规则、食谱推荐和设备烹饪流程，降低宠物鲜食制作门槛。

## 核心用户

- 关注宠物健康饮食的犬主
- 希望用鲜食替代部分干粮或罐头的家庭
- 需要根据犬只年龄、体重、品种、健康状态生成食谱的用户

## 核心场景

- 建立犬只档案
- 获取个性化鲜食建议
- 查看和选择食谱
- 跟随设备完成制作
- 记录或复用常用食谱
