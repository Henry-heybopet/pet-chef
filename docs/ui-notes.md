# UI 说明

## 视觉方向

- 整体为黑色底、高级科技感。
- 首屏保留品牌区域和鲜食机图片。
- 品牌名：Heybo Lux。
- Slogan：看得见的鲜活，定制级健康——用科技为爱宠做一顿“处方级”鲜食。
- 优先适配 iPhone 手机屏幕。

## 首页

首页不应像普通食谱 App，而应让用户快速进入“宠物个性化喂养系统”。

建议模块：

- 品牌区：Heybo Lux + slogan。
- 产品图：鲜食机照片。
- 入口 1：我的爱犬。
- 入口 2：AI 健康食谱。
- 快捷入口：最近食谱、一键开煮、本周计划、购物清单。

当前最新方向是首页删除猫相关内容，只保留狗；早期 UI 设计中曾提到狗鲜食和猫鲜食两个头像入口，需以“只保留狗”为准，猫作为后续扩展。

## 我的爱犬

### 首次进入

用户需要录入：

- 犬种。
- 体重。
- 年龄。

页面布局：

- 第一行：犬种选择，包含常见犬种和“自定义”。
- 第二行：左侧体重，右侧年龄。
- 第三行开始：食谱分类宫格。

默认值：

- 体重根据犬种平均体重自动带出。
- 年龄默认 3 岁。

犬种选择可以采用类似 KTV 点歌台的图片网格：

- 每行 3 个品种。
- 支持滑动浏览。
- 支持搜索。
- 需要至少 30 种犬种图片和名称。

### 再次进入

系统展示上次保存的宠物档案卡。用户可直接选择食谱，无需重复录入。

## AI 健康食谱

第一步输入：

- 犬种。
- 年龄。
- 体重。

界面建议：

- 三个圆形输入区域呈三角形分布。
- 保持科技感和明确的确认按钮。

第二步反馈：

- 上半区展示用户参数反馈、犬种简介、当前年龄和体重阶段的营养需求。
- 下半区展示推荐入口，例如年龄段食谱、功能食谱、鸡肉食谱、牛肉食谱。

## 食谱分类页

分类卡片：

- 幼犬食谱。
- 老年犬食谱。
- 鸡肉食谱。
- 牛肉食谱。
- 功能食谱。
- AI 食谱。

套餐卡片：

- 日常均衡。
- 低脂减肥。
- 美毛美肤。
- 骨骼保护。
- 孕期哺乳。
- 增肌高蛋白。
- 低敏肠胃。
- 老年护理。

用户选择套餐后，弹出确认信息：

```text
您为体重 XX kg、年龄 YY 岁的 ZZ 犬选择了「套餐名称」，请确认。
```

按钮：

- 返回。
- 确认。

## 食谱列表页

列表可采用类似外卖 App 或瀑布流形式。

每个食谱卡片包含：

- 食材或成品图片。
- 食谱名称。
- 标签，例如高 Omega-3、低脂、美毛。
- 制作时间。
- 简短营养成本和功效介绍。
- 展开按钮。
- 选择按钮。

展开后：

- 原图片区域展示具体食材配比。
- 配比以百分比展示。
- 展开按钮变为收起。
- 功效文字和选择按钮保留。

## 食谱详情页

页面结构：

- 顶部 20%：高清成品图片和醒目标题，例如“爆毛美肤餐”。
- 中间 50%：食材配比、克重、营养说明。
- 底部 30%：食材占比饼图和食谱功效。

食材表格建议：

- 第一列：食材照片和食材名称。
- 第二列：按犬只参数换算后的克重。
- 第三列：营养成分或主要功效。

右上角按钮：

- 食材订购。
- 食材替换。

## 食材替换模式

用户点击“食材替换”后：

- 食材卡片变为浮动可点击状态。
- 用户点击某项食材，弹出可替换列表。
- 选择替代食材后，自动更新食材克重、营养说明、烹饪参数。

示例：

- 火鸡肉可替换为鸡胸肉、鸭肉。
- 南瓜可替换为红薯、胡萝卜、土豆。

## 食谱制作页

顶部 20%：

- 显示正在为哪只犬制作哪一个食谱。

中间 70%：

- 左侧食材照片和名称。
- 中间对应克数。
- 可补充营养说明。

底部 10%：

- 返回。
- 一键烹饪。

## 烹饪页

顶部 20%：

- 品牌区，类似首页。

中间 60%：

- 左侧鲜食机照片。
- 右侧运行参数：温度、搅拌速度、火力。

底部 20%：

- 分段进度条。
- 阶段：放入食材、预加热、低温烹饪、烹饪完成。
- 每个阶段下方显示预估时长。

完成页：

- 提示“制作完成！”。
- 引导收藏食谱、加入每周计划、生成购物清单。

- `RecipeList`：食谱列表。
- `RecipeMake`：食谱详情/制作准备。
