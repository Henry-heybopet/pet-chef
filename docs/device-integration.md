# 设备联动

## 目标

设备联动的目标是让食谱数据、前端展示和鲜食机执行参数保持同步。用户选择食谱后，系统应根据犬只档案和食谱比例，计算实际食材克重和设备执行参数，再通过后端/API 层发送给设备或云平台。

## 设备能力摘要

来自中文说明书和 K1511 manual 的可执行能力：

- 时间设置。
- 速度设置：1-10 档。
- 温度设置：37°C-120°C。
- 加热功率设置：1-10 档。
- 电子秤：最大 5000g。
- Wi-Fi：TuyaSmart 配网。
- 启动/暂停/复位旋钮。

参考烹饪参数：

- 低温烹饪：85°C、1 档、8 分钟/200g。
- 蒸煮：100°C、0 档，水温到 100°C 后 5 分钟。
- 狗鲜食切碎：0°C、5 档、1 分钟。
- 热处理最大容量：1.5L。
- 冷处理最大容量：2L。

## 软件边界

### 前端

- 展示犬只档案、食谱、克重和营养说明。
- 展示设备状态、温度、速度、火力和进度。
- 触发一键烹饪、暂停、返回、重试。
- 将错误码转换为用户可理解提示。

### 后端/API

- 管理食谱数据库。
- 根据犬只参数换算食材克重。
- 根据标准食谱参数换算实际烹饪参数。
- 与 Tuya API 或设备云平台通信。
- 处理超时、重试、错误码和日志。

### 设备/云平台

- 接收温度、速度、火力、时间等指令。
- 返回设备状态、错误码和运行参数。
- 支持配网、在线状态和控制确认。

## 参数换算

数据库建议保存标准制作参数：

```text
standard_weight_g = 100 或 200
temperature_c
speed_level
power_level
cook_time_sec
stir_time_sec
water_ratio = 0.15
```

用户选择食谱后：

```text
actual_total_weight_g = 根据犬只体重、年龄、体型和食谱规则计算
ingredient_weight_g = actual_total_weight_g * ingredient_percentage
water_weight_g = actual_total_weight_g * 0.15
time_factor = actual_total_weight_g / standard_weight_g
actual_cook_time = standard_cook_time * time_factor * ingredient_adjustment
```

`ingredient_adjustment` 后续可根据食材含水量、肉类/蔬菜比例和力矩反馈修正。

## 烹饪状态机

建议统一为以下阶段：

```text
idle
ingredient_prompt
low_temp_cooking
stirring
finishing
completed
paused
error
```

UI 阶段统一为：

1. 放入食材。
2. 低温烹饪：启动即按目标转速同步加热搅拌，使用设备剩余时间驱动单一进度条。
3. 烹饪完成。

控制边界：

- 开始前下发一次 `DP107=reset`，确认退出上一次状态后再下发本次 `start`。
- 设备上报完成后下发一次 `DP107=reset`，避免当前流程残留影响下一次任务；reset 允许一次幂等重试，但必须防止完成回调重复下发。

## Tuya 配网

说明书中的配网流程：

1. 下载 App `TuyaSmart`。
2. 选择 Kitchen Appliances / Cooker。
3. 同时按住温度键和功率键 3 秒，直到听到提示音。
4. 使用 2.4 GHz Wi-Fi。
5. 等待 App 与机器连接。

软件待确认：

- 状态回传和错误码格式。

## 错误码映射

| 代码 | 含义 | 用户提示 |
| --- | --- | --- |
| E1 | 安全开关未固定 | 请重新安装鲜食杯和杯盖 |
| E2 | 温度传感器缺失 | 请确认鲜食杯安装到位 |
| E3 | 电机堵转 | 请减少食材或切小后重试 |
| E4 | 温度过高 | 请加入食物或等待降温 |
| E5 | 电机温度过高 | 请停止运行并等待机器冷却 |
| E7 | 速度切换失败 | 请停止机器后重新启动 |
| E8 | 电机 NTC 故障 | 请重启设备，仍失败则联系售后 |
| E11 | 高温高速限制 | 杯内温度高于 90°C 时请使用 4 档及以下速度 |
| E12 | 重量过载 | 请将重量减至 5kg 以下 |

## 安全限制

- 空杯不得运行。
- 盖子打开时不得高速运行。
- 运行时不得移动机器。
- 温度超过 60°C 时提示防烫。
- 温度超过 90°C 时禁止 Pulse 或 4 档以上高速。
- 高脂或少量食物建议低功率加热。
- 设备无人看管、组装、拆卸或清洁前应断电。
